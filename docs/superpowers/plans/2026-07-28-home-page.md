# 홈페이지 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `app/page.tsx`의 create-next-app 기본 템플릿을 실제 홈페이지(히어로 + 도구 3종 카드)로 교체한다.

**Architecture:** Server Component 정적 페이지. 신규 클라이언트 컴포넌트 `HomeToolCard` 1개(GA 클릭 트래킹용)만 추가하고, 나머지는 `app/page.tsx`에 인라인 SVG 아이콘 + 정적 배열로 구성한다.

**Tech Stack:** Next.js App Router (Server Component), Tailwind CSS (기존 디자인 토큰), 신규 npm 의존성 없음.

## Global Constraints

- 서버·DB·외부 API 추가 금지 — 이 작업은 순수 정적 페이지라 해당 없음 (CLAUDE.md 규칙 1)
- localStorage/sessionStorage 사용 금지, 상태는 React state로만 (CLAUDE.md 규칙 5) — 이 페이지는 상태 자체가 없음
- 새 npm 패키지 추가 전 정당화 필요, 목표는 최소 의존성 (CLAUDE.md 규칙 6) — 아이콘은 인라인 SVG로 해결, 신규 패키지 없음
- 홈은 도구 페이지가 아니므로 `<Disclaimer />`/`<AdSlot />` 대상 아님 (설계 문서 §7)
- 커밋 메시지 접두어: `feat:`, `fix:`, `content:`, `seo:`
- 참조 설계 문서: `docs/superpowers/specs/2026-07-28-home-page-design.md`

## Task 1: `HomeToolCard` 컴포넌트

**Files:**
- Create: `components/home-tool-card.tsx`

**Interfaces:**
- Consumes: `trackEvent(name: string, params?: Record<string, unknown>): void` from `@/lib/analytics` (기존 함수, 시그니처 확인 완료: `lib/analytics.ts`)
- Produces: `export function HomeToolCard(props: { step: number; icon: ReactNode; title: string; description: string; href: string }): JSX.Element` — Task 2의 `app/page.tsx`가 이 컴포넌트를 3번 렌더링하는 데 사용

이 컴포넌트는 정적 마크업 + 클릭 이벤트 트래킹만 담당하고 계산 로직이 없어 `lib/**/*.test.ts` 대상 순수 함수 테스트가 적용되지 않는다(프로젝트의 `vitest.config.ts`는 `lib/**/*.test.ts`만 포함하며 React 컴포넌트 테스트 인프라(jsdom/RTL)가 없음 — 기존 컴포넌트들(`ToolCTA`, `Disclaimer` 등)도 동일하게 자동 테스트 없이 타입체크+수동 확인으로 검증되어온 패턴). 따라서 이 태스크의 검증은 타입체크로 대체한다.

- [ ] **Step 1: `components/home-tool-card.tsx` 작성**

```tsx
"use client";

import Link from "next/link";
import type { ReactNode } from "react";
import { trackEvent } from "@/lib/analytics";

type HomeToolCardProps = {
  step: number;
  icon: ReactNode;
  title: string;
  description: string;
  href: string;
};

export function HomeToolCard({
  step,
  icon,
  title,
  description,
  href,
}: HomeToolCardProps) {
  return (
    <Link
      href={href}
      onClick={() => trackEvent("tool_cross_link", { from: "home", to: href })}
      className="flex flex-col gap-3 rounded-lg border border-steel/30 bg-white p-6 transition hover:border-amber hover:shadow-md"
    >
      <div className="flex items-center gap-2">
        <span className="flex h-6 w-6 items-center justify-center rounded-full bg-navy text-xs font-bold text-ivory">
          {step}
        </span>
        {icon}
      </div>
      <p className="text-lg font-semibold text-navy">{title}</p>
      <p className="text-sm text-navy/70">{description}</p>
    </Link>
  );
}
```
