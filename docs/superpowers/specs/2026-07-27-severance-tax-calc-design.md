# 퇴직소득세 계산 로직 (Phase 1) — 설계

작성일: 2026-07-27 · 대상: CHECKLIST.md §3 "퇴직소득세 계산기" 중 계산 로직 부분
(화면/콘텐츠/SEO는 Phase 2에서 별도 설계·계획)

## 배경

§2(공통 기반)가 완료되어 브랜드 레이아웃·공통 컴포넌트가 준비됐다. 다음은 대표 도구인
퇴직소득세 계산기다. CLAUDE.md의 검증 게이트("홈택스 모의계산 대조 오차 0원 확인 전까지
다음 도구 개발 금지")가 이 도구에 걸려 있으므로, 계산 로직(순수 함수)을 먼저 완성하고
테스트로 고정한 뒤 나머지(화면·콘텐츠)를 진행한다.

**게이트 상태 — 중요:** 운영자가 홈택스 실측값을 아직 제공하지 않기로 했다("일단 계산
로직부터 구현, 검증은 나중에"). 따라서 이번 Phase 1의 테스트 기댓값은 **SPEC.md §2의
공식을 그대로 손계산한 값**이며, 홈택스 대조는 아직 안 됐다. 테스트 파일과 최종 보고에
이 사실을 명시하고, §4(도구 2) 착수는 계속 금지 상태로 둔다.

## 2. `lib/calculators/severance-tax.ts`

```ts
export function calculateSeveranceTax(input: {
  severancePay: number; // 퇴직급여 총액 (원)
  serviceYears: number; // 근속연수 (정수, 1년 미만은 호출부에서 올림 처리 완료된 값)
}): {
  serviceYearDeduction: number;
  convertedSalary: number;
  convertedSalaryDeduction: number;
  taxBase: number;
  convertedTax: number;
  severanceTax: number; // 퇴직소득세
  localIncomeTax: number; // 지방소득세
  netAmount: number; // 실수령액
}
```

SPEC 8단계를 순서대로 구현, `TAX_TABLES[2026]`만 참조(상수 하드코딩 금지).
**단수처리 가정(미검증):** SPEC.md §2가 2·3·5단계(환산급여·환산급여공제·환산산출세액)의
단수처리 규칙을 명시하지 않아, 이 구현은 해당 단계들에서 반올림(`Math.round`)을
적용한다고 가정했다. 6번(퇴직소득세)과 7번(지방소득세) 산출 시에는 SPEC이 명시한 대로
`Math.floor`(절사)를 적용한다. 반올림 가정은 실제 홈택스 계산이 절사를 쓸 가능성이
있어 틀릴 수 있다 — 홈택스 실측값을 받으면 이 가정을 가장 먼저 재검증한다.

**✅ 검증 완료 (2026-07-27):** 홈택스 실측 대조 결과 이 반올림 가정은 정확했다. 다만
근속연수 계산에 별도 버그가 있었고, 실수령액 계산에는 10원 단위 절사가 추가로 필요했다.
자세한 내용은 `docs/superpowers/specs/2026-07-27-hometax-verification-fix-design.md` 참고.

## 3. `lib/calculators/service-years.ts`

SPEC 입력 규칙("입사일/퇴사일 → 근속연수 자동 산출, 1년 미만 올림")을 위한 별도 순수 함수:

```ts
export function calculateServiceYears(startDate: string, endDate: string): number
```

## 검증 케이스 손계산 (테스트 기댓값 출처)

### (a) 퇴직급여 1억, 근속 10년
1. 근속연수공제(10년, 6~10구간) = 500만 + 200만×(10−5) = 15,000,000
2. 환산급여 = (100,000,000−15,000,000)÷10×12 = 102,000,000
3. 환산급여공제(1억200만, ≤3억구간) = 61,700,000+(102,000,000−100,000,000)×0.45 = 62,600,000
4. 과세표준 = 102,000,000−62,600,000 = 39,400,000
5. 환산산출세액(≤5,000만구간) = 39,400,000×0.15−1,260,000 = 4,650,000
6. 퇴직소득세 = 4,650,000÷12×10 = **3,875,000**
7. 지방소득세 = **387,500**
8. 실수령액 = 100,000,000−3,875,000−387,500 = **95,737,500**

### (b) 퇴직급여 2억, 근속 20년
1. 근속연수공제(20년, 11~20구간) = 1,500만+250만×(20−10) = 40,000,000
2. 환산급여 = (200,000,000−40,000,000)÷20×12 = 96,000,000
3. 환산급여공제(9,600만, ≤1억구간) = 45,200,000+(96,000,000−70,000,000)×0.55 = 59,500,000
4. 과세표준 = 96,000,000−59,500,000 = 36,500,000
5. 환산산출세액(≤5,000만구간) = 36,500,000×0.15−1,260,000 = 4,215,000
6. 퇴직소득세 = 4,215,000÷12×20 = **7,025,000**
7. 지방소득세 = **702,500**
8. 실수령액 = 200,000,000−7,025,000−702,500 = **192,272,500**

### (c) 퇴직급여 5,000만, 근속 5년
1. 근속연수공제(5년, ≤5구간) = 100만×5 = 5,000,000
2. 환산급여 = (50,000,000−5,000,000)÷5×12 = 108,000,000
3. 환산급여공제(1억800만, ≤3억구간) = 61,700,000+(108,000,000−100,000,000)×0.45 = 65,300,000
4. 과세표준 = 108,000,000−65,300,000 = 42,700,000
5. 환산산출세액(≤5,000만구간) = 42,700,000×0.15−1,260,000 = 5,145,000
6. 퇴직소득세 = 5,145,000÷12×5 = **2,143,750**
7. 지방소득세 = **214,375**
8. 실수령액 = 50,000,000−2,143,750−214,375 = **47,641,875**
