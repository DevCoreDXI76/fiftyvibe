# PRD — fiftyvibe.kr 퇴직연금 계산 도구

작성일 2026-07-26 · 버전 1.0 · 작성: 피프티바이브 & Claude

## 1. 배경과 문제
- 퇴직연금(DB/DC/IRP) 가입자는 "퇴직금 받을 때 세금이 얼마인지", "일시금과 연금 중 뭐가 유리한지", "DB에서 DC로 갈아타도 되는지"를 검색하지만, 기존 결과물은 단편적 블로그 글이거나 계산기 단독 페이지 수준.
- 운영자 본인이 2027년 3월 DB→DC 전환 예정인 실사용자로서, 이 여정 전체를 커버하는 도구+콘텐츠 세트를 만든다.

## 2. 목표
| 구분 | 목표 | 측정 |
|---|---|---|
| 런칭 | 4주 내 도구 3종 + 가이드 5편 배포 | 배포일 |
| 트래픽 | 3개월 내 월 5,000 세션 | GA4 |
| SEO | "퇴직소득세계산기" 구글 1페이지 진입 (3개월) | 서치콘솔 |
| 수익 | 애드센스 승인 + 첫 수익 발생 (2개월) | 애드센스 리포트 |

## 3. 타겟 사용자
- P1: 퇴직 예정/이직 중 직장인 — "퇴직금 세후 얼마 받나" (트래픽의 대부분)
- P2: 50대 전후 DB 가입자 — "DC 전환 유불리" (전환율 높은 코어 타겟, 운영자와 동일 페르소나)
- P3: 퇴직급여 수령 방식 고민자 — "일시금 vs 연금"

## 4. 범위
### Phase 1 (이번 릴리즈)
1. **퇴직소득세 계산기** (대표 도구) — 타겟: 퇴직소득세계산기 8,080/월(광고경쟁 낮음), 세후·퇴직금세금 클러스터 ~2만/월
2. **일시금 vs 연금수령 세금 비교 계산기** — 타겟: 퇴직연금수령방법 14,160/월
3. **DB/DC 전환 계산기** — 타겟: DBDC 클러스터 ~500/월 (틈새·차별화·E-E-A-T 축)
4. 가이드 글 5편, about/privacy/contact

### Phase 1.5 (런칭 후)
- 자산배분 시뮬레이터 (관문 키워드 약해 연기, DECISIONS.md D-05)
- 가이드 글 8~10편으로 증량 → 애드센스 신청

### Phase 2 (검토 후보)
- 실업급여 계산기 (113,200/월, 광고경쟁 낮음 — 키워드 실측 근거)
- 부동산 세트 (복비·취득세·전월세전환)
- 기존 coredxi 서브도메인 사이트(salaryfit/lottolab/saju) 이전 여부 판단

### 명시적 비범위 (하지 않는 것)
- 특정 ETF/펀드 추천 (투자자문업 규제, D-02)
- 실시간 금리·시세 연동 (D-03)
- 회원가입, 데이터 저장, 커뮤니티 기능

## 5. 수익 모델
- 구글 애드센스 (법인 CoreDXI 명의 계정)
- 광고 슬롯: 도구 결과 하단 1 + 설명 섹션 중간 1 (레이아웃 시프트 방지 높이 고정)
- 승인 조건: 색인 완료 + 총 11페이지 이상 + 개인정보처리방침(쿠키 고지 포함)

## 6. 성공을 좌우하는 요소
1. **계산 정확성** — 홈택스 대조 오차 0원. 이 사이트의 존재 이유
2. 도구 간 여정 연결 — 세금 계산 → 수령 방식 비교 → DC 전환 검토 (내부 링크 + 값 전달)
3. 운영자 실경험 콘텐츠 — "내가 DC 전환을 결정한 과정" (E-E-A-T)
4. 채널 시너지 — 유튜브 "바이브랩 만들기" 시리즈가 사이트 제작기를 콘텐츠화
