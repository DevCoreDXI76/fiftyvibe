## 2. 도구 1: 퇴직소득세 계산기 `/tools/severance-tax`

### 입력
| 필드 | 형식 | 규칙 |
|---|---|---|
| 퇴직급여 총액 | 원 | 천단위 콤마 자동, 비과세 제외 금액 기준 |
| 입사일/퇴사일 | date | 근속연수 자동 산출(1년 미만 올림) |
| 근속연수 직접 입력 | 년 | 날짜 입력과 토글 전환 |

### 계산 (순서 고정)
1. 근속연수공제: ≤5년 100만×n / 6~10년 500만+200만×(n−5) / 11~20년 1,500만+250만×(n−10) / >20년 4,000만+300만×(n−20)
2. 환산급여 = (퇴직급여 − 근속연수공제) ÷ n × 12
3. 환산급여공제: ≤800만 전액 / ≤7,000만 800만+초과분×60% / ≤1억 4,520만+초과분×55% / ≤3억 6,170만+초과분×45% / >3억 15,170만+초과분×35%
4. 과세표준 = 환산급여 − 환산급여공제
5. 환산산출세액 = 과세표준 × 기본세율(누진공제): 1,400만↓6% / 5,000만↓15%(126만) / 8,800만↓24%(576만) / 1.5억↓35%(1,544만) / 3억↓38%(1,994만) / 5억↓40%(2,594만) / 10억↓42%(3,594만) / 초과 45%(6,594만)
6. 퇴직소득세 = 환산산출세액 ÷ 12 × n (원단위 절사 규칙 홈택스와 일치시킬 것)
7. 지방소득세 = 퇴직소득세 × 10%
8. 실수령액 = 퇴직급여 − 6 − 7

### 출력
- 히어로 숫자: 실수령액 / 보조: 총 세금, 실효세율%
- 아코디언 "계산 과정 보기": 1~7단계 표
- CTA → 도구 2 (쿼리로 금액·근속 전달)

### 검증 게이트 (통과 전 도구 2 착수 금지)
홈택스 모의계산 대조, 오차 0원: (a) 1억/10년 (b) 2억/20년 (c) 5,000만/5년
`lib/calculators/severance-tax.test.ts`에 케이스 고정

### SEO
- title: `퇴직소득세 계산기 (2026) — 퇴직금 실수령액 세후 계산 | 피프티바이브`
- JSON-LD: WebApplication + FAQPage(4문항) + BreadcrumbList

## 3. 도구 2: 일시금 vs 연금 비교 `/tools/lump-vs-pension`
- 입력: 퇴직급여·근속연수(쿼리 자동 수신), 수령기간(10/15/20/직접), 개시 나이(55~70)
- 일시금 세금: 도구 1 로직 재사용
- 연금 세금: 이연퇴직소득세 감면 — 1~10년차 수령분 70%, 11년차~ 60% / 균등분할 가정 / 연차별 합산
- 출력: 총 세금 비교 막대(recharts), 절세액(원·%), 연차별 표(아코디언)
- 고지: 운용수익분 연금소득세(3.3~5.5%)는 별도, 본 계산은 이연퇴직소득 기준
- title: `퇴직금 일시금 vs 연금 수령 세금 비교 계산기 | 피프티바이브`

## 4. 도구 3: DB/DC 전환 계산기 `/tools/db-dc`
- 입력: 현재 연봉, 연 임금상승률%, 잔여 근속연수, DC 기대수익률%, (선택) 임금피크제(시점·감액률)
- DB = 퇴직 시점 30일분 평균임금 × 총 근속연수 (임금상승률 복리, 피크 시 감액 반영)
- DC = Σ[각 연도 임금총액÷12] × (1+수익률)^잔여연수, 연 복리
- 출력: 최종 금액 비교 + 연도별 라인 차트 + **손익분기 수익률 한 줄** ("연 X.X% 이상이면 DC 유리") + 피크 적용 시 최적 전환 시점
- 고지: 단순화 모델(급여구성·수수료 미반영), 투자 권유 아님, DC 전환 비가역성 경고
- title: `퇴직연금 DB DC 전환 계산기 — 유불리 비교 | 피프티바이브`
