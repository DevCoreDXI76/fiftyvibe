## 3. 신규 가이드 주제 후보 (4편)

아래 4개는 웹 검색으로 확인한 실제 검색 수요가 있는 주제이지만, **정확한 월간 검색량·경쟁 강도는 검증되지 않은 추정치**다. 착수 전 네이버 키워드도구 또는 구글 키워드 플래너로 실측을 권장한다.

### G1. "IRP 연금수령한도 계산법" (최우선)

- 예상 검색 키워드: `IRP 연금수령한도`, `연금 수령한도 계산`, `IRP 한도 초과 세금`
- 경쟁 강도: 중간 — 증권사·은행 블로그가 개념 설명 위주로 다수 존재하나, **계산 과정을 단계별로 보여주는 글은 적음** (틈새)
- 개발 난이도: 중 — 계산 로직 자체는 이미 있는 tax-tables 상수로 커버 가능한지 확인 필요. 안 되면 계산 예시 없이 개념+표 설명으로 축소
- 수익 잠재력: 중상 — IRP 관련 검색은 금융 카테고리라 애드센스 단가가 상대적으로 높은 편
- 참고: 기존 은행권 콘텐츠(KB, 신한, 미래에셋 등)가 이미 많으므로 **"세금 계산 관점"으로 차별화**할 것 (일반 개념 설명 반복 금지)

### G2. "임금피크제 앞두고 DB→DC 전환, 언제가 유리한가"

- 예상 검색 키워드: `임금피크제 DC 전환`, `DB DC 전환 시기`, `임금피크제 퇴직연금`
- 경쟁 강도: 중간 — 유사 주제 블로그 존재하나 대부분 일반론. **운영자 본인이 내년 3월 실제 전환 예정자**라는 E-E-A-T 요소를 살릴 수 있는 주제
- 개발 난이도: 중 — 특정 수익률 전망이나 상품 언급 없이 "구조"만 설명해야 하므로 문구 검토에 신경 쓸 것 (CLAUDE.md 규칙 2 위반 소지 주의)
- 수익 잠재력: 중 — 40~50대 타깃 트래픽, 사이트의 DB/DC 전환 계산기 도구와 직결되어 **도구 유입 전환에도 기여**
- 도구 페이지(DB/DC 전환 계산기)와 강하게 상호 링크할 것

### G3. "퇴직금 중간정산 후 근속연수 합산 규칙"

- 예상 검색 키워드: `퇴직금 중간정산 근속연수`, `중간정산 후 퇴직소득세`, `중간정산 재직기간 합산`
- 경쟁 강도: 낮음 — 1주차에 퇴직소득세 계산기 FAQ에 "중간정산 받은 적 있으면?" 항목을 넣었는데, 이를 **독립 가이드로 확장**하면 검색 커버리지 확대
- 개발 난이도: 낮음 — 기존 계산기 FAQ 답변을 뼈대로 확장, 계산 예시 1~2건 추가
- 수익 잠재력: 중 — 검색량은 크지 않으나 경쟁이 거의 없어 상위 노출 가능성 높음 (롱테일)

### G4. "55세 이전 퇴직금 수령 시 세금 불이익"

- 예상 검색 키워드: `55세 이전 퇴직금 수령`, `IRP 없이 퇴직금 받으면`, `조기 퇴직금 수령 세금`
- 경쟁 강도: 낮음~중간
- 개발 난이도: 낮음 — 개념 설명 중심, 계산 예시는 기존 계산기 결과 링크로 대체 가능
- 수익 잠재력: 중 — 이직·퇴사 관련 검색 수요와 겹쳐 유입 다양성 확보에 도움

**예비 후보** (T0에서 중복 발견 시 교체용): "55세 이후 연금 수령 시 건강보험료 영향", "퇴직소득세 지방소득세 계산", "퇴직연금 담보대출과 세금"
