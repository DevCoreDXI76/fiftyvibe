## 0. 배경 — v2에서 무엇이 바뀌었나

08-12 거절 사유("가치가 별로 없는 콘텐츠")에 대한 1·2주차 대응(볼륨 + 신뢰 페이지)은 2026년 표준 처방과 일치한다. 다만 8/13 조사에서 확인한 2026년 심사 트렌드 기준으로 기존 v1 계획이 놓친 레버 3개를 반영한다.

1. **재신청 트리거를 날짜 → 조건으로 변경.** "변경분 색인 + 최소한의 유기 유입 후 재신청"이 2026년 공통 권고. 트래픽 제로 상태의 신청 자체가 거절 요인으로 지목됨. v1의 "색인이 늦어도 재신청을 막을 필요 없음" 문구는 폐기한다.
2. **기존 가이드 경험 보강(T3 신설).** 도구 UI는 편집 콘텐츠로 인정되지 않고, AI 생성물과 구별되지 않는 일반론 가이드는 볼륨과 무관하게 거절 1순위 패턴. 우리의 최대 차별점은 운영자가 실제 DB→DC 전환(2027-03)을 앞둔 당사자라는 사실이며, 이를 About에만 두지 않고 가이드 본문에 주입한다. **신규 편수 추가 금지는 유지**하되, 기존 편 보강은 예외로 허용한다.
3. **O-05 원인 재점검을 재신청 전으로 승격(T4 신설).** 심사 크롤러가 보는 순간의 페이지가 PSI 모바일 61점 / LCP 14.2초라는 것은 심사 리스크이기도 하다. 광고 코드/ads.txt는 유지한 채 원인 재확인과 완화책 검토만 수행한다.

coredxi.com 처리는 **옵션 B(사이트 목록에서 제거)로 결정됨** (08-13, 운영자 결정) — T1은 실행 절차로 전환.

## 4. T3. 기존 가이드 경험 보강 (content:) — v2 신설

목적: "잘 정리된 일반론"을 "당사자의 기록"으로 바꾼다. 대상은 검색 유입 가능성이 높거나 도구와 직결된 **기존 가이드 중 3~5편** (편 선정은 서치콘솔 노출 데이터 + 도구 연관도 기준으로 운영자 확인).

각 대상 편에 다음 중 2가지 이상을 주입:

1. 운영자 본인 케이스 수치 기반 예시 ("근속 25년, 내년 3월 DB→DC 전환 예정인 내 경우…" — 구체 금액은 가공 수치 사용 가능하나 시나리오는 실제 상황 기반)
2. 홈택스 모의계산과 도구 결과 대조 과정 스크린샷 (검증 게이트에서 이미 수행한 것을 콘텐츠화)
3. 직접 해보며 부딪힌 함정/오해 포인트 ("나도 처음엔 X로 알고 있었는데 실제로는 Y")
4. 결정 과정 서술 (왜 전환을 고민하는지, 어떤 기준으로 판단하는지)

주의:

- 특정 금융상품 언급 금지 규칙(D-02) 그대로 적용 — 경험 서술은 제도·세금 범위로 한정

- 보강 후 해당 URL은 §6의 색인 재요청 목록에 추가
