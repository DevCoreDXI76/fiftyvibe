목적: 이미 검토하고 내린 결정을 기록해, 이후 세션(사람이든 AI든)이 같은 논의를 반복하거나 결정을 무심코 되돌리는 것을 방지한다.
규칙: 결정 변경은 새 항목(D-XX 개정)으로 추가하며, 기존 항목은 삭제하지 않는다.

## D-01. 첫 사이트 주제: 퇴직연금 도구 (부동산 대신)
- 결정일: 2026-07-26 / 상태: 확정
- 선택지: (A) 부동산·금융 계산기 (B) 직장인 계산기 (C) 퇴직연금 도구
- 결정: C
- 근거: 운영자가 2027년 3월 DB→DC 전환 예정인 실사용자 → 도메인 지식·E-E-A-T·콘텐츠 진정성. 연금 키워드 CPC도 상위권
- 트레이드오프: 부동산 대비 시장 크기는 작으나 경쟁 강도가 낮음. 부동산은 Phase 2 후보로 보존

## D-02. 특정 금융상품(ETF) 추천 기능 배제
- 결정일: 2026-07-26 / 상태: 확정 (절대 규칙)
- 배경: "성향 입력 → ETF 추천" 아이디어 검토 결과, 개인 맞춤 종목 추천은 자본시장법상 투자자문업 등록 대상. 무등록 시 법적 리스크 + 애드센스 YMYL 감점
- 결정: 종목 추천 금지. 비율 기반 자산배분 시뮬레이터·교육 콘텐츠까지만 허용
- 트레이드오프: 사용자가 가장 원하는 "찍어주기"를 포기하는 대신 법적 안전과 지속 가능성 확보

## D-03. 서버·DB·외부 API 없는 클라이언트 완결 구조
- 결정일: 2026-07-26 / 상태: 확정 (절대 규칙)
- 근거: 고정비 연 ~2만 원(도메인만), 유지보수 최소화, 1인 운영 지속 가능성
- 트레이드오프: 실시간 금리·시세 기능 포기. 세율표는 연 1회 수동 갱신
- 파생 규칙: "실시간 반영" 류 기능 제안은 이 결정에 위배됨

## D-04. 대표 도구 변경: DB/DC → 퇴직소득세 계산기
- 결정일: 2026-07-26 / 상태: 확정
- 근거: 네이버 키워드 실측 — DBDC 클러스터 월 ~500 vs 퇴직소득세계산기 8,080(광고경쟁 낮음·광고 0) + 주변 클러스터 ~2만
- 트레이드오프: DB/DC는 검색량이 작지만 경쟁 부재 + 운영자 스토리 자산이라 3순위로 유지 (폐기 아님)

## D-05. 자산배분 시뮬레이터 Phase 1.5 연기
- 결정일: 2026-07-26 / 상태: 확정
- 근거: 관문 키워드 부재 (위험자산70·안전자산30 월 20 미만). "퇴직연금ETF"는 정보성 → 가이드 글이 적합
- 재평가 조건: 런칭 후 서치콘솔에서 관련 유입이 확인되면 착수

## D-06. 신규 독립 도메인 (coredxi.com 서브도메인 대신)
- 결정일: 2026-07-26 / 상태: 확정
- 선택지: (A) coredxi 루트 — 불가(B2B 사이트 사용 중) (B) salaryfit 통합 (C) 신규 서브도메인 (D) 신규 독립 도메인
- 결정: D
- 결정적 근거: B2B 잠재 고객의 실사 리스크 — 법인 도메인 하위에 로또·사주 사이트가 노출되면 "AI 전문 B2B 기업" 신뢰에 역풍. 수익형 자산은 법인 브랜드와 분리
- 트레이드오프: salaryfit의 기존 SEO 자산과 (있다면) 애드센스 기승인 이점을 포기하고 제로 스타트 선택. 대신 브랜드 격리 + 자산 매각 가능성 확보
- 후속: 기존 3개 사이트(salaryfit/lottolab/saju)의 이전·정리는 Phase 2에서 별도 판단

## D-07. 사업자: 기존 법인(CoreDXI) 그대로 사용
- 결정일: 2026-07-26 / 상태: 확정
- 근거: 도메인·브랜드·사업자는 별개 층위. 새 도메인도 법인 명의 소유 가능. 개인사업자 신설은 소액 수익 대비 기장·신고 부담만 추가
- 실무 확인 필요(오픈): ① 정관·사업자등록 사업목적에 광고업 류 포함 여부 ② 애드센스 외화 매출 부가세(영세율) 처리 — 세무사 확인
- 구조: 법인 = 소유·계약 주체(비노출) / 브랜드 = 피프티바이브(전면)

## D-08. 브랜드 통합: fiftyvibe.kr 단일 도메인 (채널·사이트 통일)
- 결정일: 2026-07-26 / 상태: 확정
- 배경: 당초 "채널명·도구 도메인 분리" 원칙이었으나, vibelab.kr 선점 확인 + fiftyvibe.kr 가용
- 근거: ① 검색 사용자에게 도메인명 중요도 낮음 ② YMYL에서 "누가 만들었나"가 일관되면 E-E-A-T 유리 ③ 1인 운영에 브랜드 2개는 관리 비용 2배
- 트레이드오프: 도구 포트폴리오 단독 매각 가능성 저하 (필요 시 향후 301 이전으로 해결)
- 구조 파생: 서브도메인이 아닌 서브디렉토리(/tools/) — 도메인 권위 합산

## D-09. 유튜브·블로그: 개인 브랜드(피프티바이브)로 전환
- 결정일: 2026-07-26 / 상태: 실행 완료 (채널명·프로필·배너)
- 근거: 콘텐츠 실체가 "김부장 1인 개발 성장기" = 개인 콘텐츠. 1인 법인의 최강 마케팅 자산은 창업자 개인 브랜드. B2B(CoreDXI)와 관객 분리
