### T1. 공용 컴포넌트 `ToolGuide` 신설 (feat:)

도구 페이지 하단에 붙는 본문 섹션 컴포넌트. 구조:

```
components/tool-guide.tsx
  - props: sections (제목+본문 children), faqItems ({ question, answer }[])
  - 시맨틱 마크업: <section> + <h2>/<h3>, FAQ는 <details>/<summary> 또는 열림 상태 리스트
  - FAQ가 있으면 FAQPage JSON-LD를 <script type="application/ld+json">으로 렌더링
  - 스타일: 밝은 배경 + 네이비 텍스트 기본, 제목 뒤 앰버 블록 커서(▮) 모티프 유지
```

JSON-LD 스펙 (FAQPage):

```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    { "@type": "Question", "name": "질문", "acceptedAnswer": { "@type": "Answer", "text": "답변" } }
  ]
}
```

주의: JSON-LD의 답변 텍스트는 화면에 보이는 답변과 반드시 동일해야 함 (구조화 데이터 가이드라인).

### T2. 퇴직소득세 계산기 페이지 본문 증량 (content:) — 최우선

계산기 아래에 ToolGuide로 다음 섹션 추가. **본문 합계 1,500자 이상** (공백 제외 기준 권장 2,000자+).

섹션 구성:

1. **이 계산기가 계산하는 것**
   - 퇴직소득세 정의, 분류과세라는 특성(종합소득과 합산 안 됨)
   - 계산 근거: 2026년 소득세법 기준임을 명시 + 세율표는 사이트가 관리하는 상수 기준이라는 문구
   - 홈택스 모의계산과 오차 0원 검증을 거쳤다는 신뢰 문구 (실제 검증 완료된 사실)
2. **계산 구조 4단계 해설**
   - ① 퇴직소득금액 − 근속연수공제 → ② 환산급여(×12÷근속연수) → ③ 환산급여공제 → ④ 과세표준×세율÷12×근속연수 (연분연승)
   - 각 단계를 2~3문장으로. "왜 근속연수로 나눴다 다시 곱하는가"(장기 근속 세부담 완화 취지) 설명 포함
3. **계산 예시 2건 (단계별 풀이)**
   - 예시 A: 근속 20년, 퇴직금 2억 원 — 각 단계 금액을 표로
   - 예시 B: 근속 8년, 퇴직금 5천만 원
   - **중요**: 예시 수치는 반드시 `lib/calculators`의 실제 함수를 돌려 나온 값으로 작성. 손계산으로 쓰지 말 것 (수치 틀리면 신뢰도 역효과)
4. **FAQ 6문항** (아래 질문 사용, 답변은 각 2~4문장으로 작성)
   - 퇴직소득세는 왜 월급 소득세와 따로 계산하나요?
   - 근속연수는 어떻게 계산하나요? (1년 미만 올림 규칙)
   - 퇴직금을 IRP로 받으면 세금이 어떻게 되나요? (과세이연 개념만, 상품 추천 금지)
   - 중간정산을 받은 적이 있으면 어떻게 입력하나요?
   - 이 계산기 결과와 회사가 알려준 금액이 다르면?
   - 계산 결과는 법적 효력이 있나요? (Disclaimer 연결)
5. **관련 가이드 내부 링크 블록** — 기존 가이드 10편 중 관련 3~4편 링크
